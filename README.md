# 🌳 Tree Info App

A super-detailed Flutter application for recording nature by attaching images and even a profile image to journal entries related to trees. Lightweight and simple, yet really cool-looking; operates inspired by nature for a user experience. 

> Completed as a personal Flutter learning project and.. as part of a school project.

---

## Features

- 📝 **Write & Save Entries**  
  Creates a title, writes a body, attaches multiple pictures to your journal entry.

-  **Nature Inspired User Experience**  
  Give the same calm beauty that nature provided through the background and images.

-  **Like Button**  
  Just like an entry using a heart button toggle.

-  **Profile Image Upload**  
  Upload a profile image that will display on the top right of your home screen.

-  **Multiple Image Picker**  
  Pick and display multiple images per journal entry.

---

##  Technologies Used

- **Flutter** (User Interface framework) 
- **Dart** (Programming Language) 
- **Provider** (State Management) 
- **Image Picker** (Used to select images from device)

---

##  How It Works 
- App starts on the `MyHomePage` screen.
- Click the **+** Floating Action Button to add a new entry. 
- In a new entry screen, you can, 
  - Set a title 
  - Create a body 
  - Pick one or more images
  - Pick a profile image - The first image selected will be your profile image. 
- After saving, the entry will show up with all of the selected images.
